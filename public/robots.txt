# ============================================================
# 検索エンジン・AIボットへの案内 / robots.txt
#
# 2026年9月に本公開しました。すべてのロボットを歓迎しています
# （Google・Bing などの検索エンジンも、ChatGPT・Claude などのAIも）。
# Public since September 2026. All crawlers welcome, search engines
# and AI assistants alike.
#
# ロボットの名前を1つずつ書く必要はありません。下の「*」がすべてに
# 当てはまります。むしろ名前を書くと、そのロボットは自分の名前の
# ところだけを読んで「*」を無視するので、/admin/ を見に行くように
# なってしまいます。だから、あえて短くしてあります。
#
# Deliberately minimal. A crawler obeys exactly one group — the most
# specific match for its own name — and inherits nothing from the
# others, so naming individual bots here would silently drop the
# /admin/ rule for exactly those bots.
#
# 「登録してほしくないページ」（/thanks/ と /business-card/）は、
# ページ自体に noindex を入れてあります。ここで Disallow にすると、
# ロボットがその noindex を読めなくなるので、書いていません。
# ============================================================

User-agent: *
Allow: /
Disallow: /admin/
